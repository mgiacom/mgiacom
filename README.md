## Notice (August 2026)

Following our previous discovery of a bug in AliSim and the realisation that our previous test was not as discerning as expected we have now developed a new test based on the use of the Goldman test. This follows and extend the work of Wang et al. (2018). This page will be updated in September following my return from holidays. In the meantime contact Davide Pisani (Davide.Pisani@bristol.ac.uk) if you need advice. 

Based on results of tests we already performed, it is highly unlikely that results obtained using our previous procedure will be overturned. The new test has for now proved more discerning usually suggesting CAT-PMSF significantly outperform C10-C60 type models with all considered model dataset.

## Notice (July 2026)

The **tardigrades_catpmsf** repository has been temporarily withdrawn while we update the workflow following the identification of a bug in AliSim that may affect simulations.

Our original script was implicitly designed to avoid the effect of the bug. However, it emerged that because of that it might lack some precision. While preliminary comparisons demonstrates that our original script is sufficient to discriminate between LG and other across-site compositionally homogeneous models and CAT-PMSF, its behaviour is less predictable when used to compare alternative across-site compositionally heterogeneous models.

We are currently updating the workflow and will restore the repository once the revised implementation has been validated.

If you have already used this pipeline or have any questions, please feel free to get in touch.
